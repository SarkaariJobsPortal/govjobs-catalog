# govjobs-catalog

Static, public `catalog.json` for the GovJobs Android app. This repo holds
only published job-catalog data — no user data, no profiles, no app code.
Generated by the `catalog_pipeline` in the private GovJobs project.

Served via GitHub Pages at the root of this repo:
`https://<your-username>.github.io/govjobs-catalog/catalog.json`

To publish a new catalog: overwrite `catalog.json` with a new pipeline run's
output and push. See `docs/CATALOG_OPERATIONS.md` in the main project for
the full publish/rollback process.
